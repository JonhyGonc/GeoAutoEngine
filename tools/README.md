# Ferramentas

Utilitários de manutenção e geração de evidências do GeoAutoEngine 3.0. Não contém código carregado pelo plugin.

- `capture-stage2-interpretation-oracle.py`: captura o oráculo de interpretação do legado congelado;
- `capture-stage3-drawing-oracle.py`: captura somente a preparação gráfica independente do DWG;
- `update-reference-manifest.ps1`: recalcula tamanhos e SHA-256 do acervo `reference/`.
