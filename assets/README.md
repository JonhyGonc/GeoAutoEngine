# Assets

Ativos utilizados pelo GeoAutoEngine 3.0 são mantidos aqui e empacotados no bundle nativo.

`blocks/` contém somente as sete definições com associação segura confirmada pelo catálogo da Etapa 3. Elas são cópias byte a byte da baseline congelada; o legado em `GeoAutoEngine.Legacy/assets` não foi modificado. Os hashes estão em `blocks/MANIFEST.sha256`.
